# Niver da Bê\n\nConvite interativo de aniversário com envelope animado, cartões sobrepostos e confirmação de presença com acompanhantes.\n\n## Desenvolvimento\n\nRequer Node.js 22.13 ou superior e pnpm.\n\n```sh\npnpm install\npnpm dev\n```\n\n## Publicação\n\nO projeto usa React, Vinext e Cloudflare Workers. A confirmação de presença depende de um banco Cloudflare D1 chamado `DB`, com a migração em `drizzle/`. As credenciais e os dados dos convidados não fazem parte deste repositório.\n\nSite: https://niver-da-be.creastezgin123.chatgpt.site\n
